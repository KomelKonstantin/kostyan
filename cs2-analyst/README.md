# cs2-analyst

CLI-инструмент для **вероятностного** анализа матчей CS2. Принимает ссылку на матч HLTV
(или названия двух команд), собирает статистику и выдаёт отчёт: вероятности исходов,
справедливые коэффициенты, сравнение с вашими коэффициентами и рекомендацию.

> ⚠️ Инструмент оценивает вероятности и ничего не гарантирует. В CS2 высокая дисперсия:
> исход с вероятностью 70 % не сбывается примерно в каждом третьем матче. Коэффициенты
> модели подобраны экспертно и **не откалиброваны** на истории — относитесь к ним как к
> структурированному мнению, а не как к истине.

## Установка

Python 3.11+.

```bash
cd cs2-analyst
pip install -e .            # даёт команду cs2-analyst
# или без установки:
pip install -r requirements.txt && python -m cs2_analyst --help
```

## Быстрый старт

```bash
# 1. По ссылке на матч HLTV
cs2-analyst analyze https://www.hltv.org/matches/2380000/team-a-vs-team-b-event --odds odds.json

# 2. По названиям команд (формат и LAN задаются флагами)
cs2-analyst analyze --teams "Vitality" "Spirit" --bo 3 --lan --odds odds.csv

# 3. Полностью вручную (если HLTV недоступен)
cs2-analyst template > match.json      # заполните известные поля, остальное — null
cs2-analyst analyze --data match.json --odds odds.json

# Демо на вымышленных данных
cs2-analyst analyze --data examples/demo_match.json --odds examples/demo_odds.json
```

Полезные флаги:

| Флаг | Назначение |
|---|---|
| `--odds` | Коэффициенты: JSON/CSV строкой, путь к файлу или `-` (stdin) |
| `--data` | Ручные данные JSON; дополняют и **перекрывают** данные HLTV |
| `--html-dir` | Каталог с HTML-страницами HLTV, сохранёнными из браузера |
| `--bo 1/3/5`, `--lan` / `--online` | Формат, если не определился автоматически |
| `--map-pool ...` | Актуальный пул карт (по умолчанию берётся из статистики) |
| `--maps ...` | Известные карты серии по порядку |
| `--date YYYY-MM-DD` | Дата «сегодня» для затухания формы |
| `--min-edge 0.03` | Порог EV для «перевеса» |
| `--format md/json`, `--out file` | Формат и файл отчёта |
| `--no-players` | Не загружать страницы игроков (на 10 запросов меньше) |
| `--offline`, `--no-fetch` | Только кэш / вообще без сети |

Коды выхода: `0` — успех, `2` — ошибка входных данных, `3` — HLTV закрыт Cloudflare.

## Источники данных и политика доступа к HLTV

Порядок действий:

1. **Вежливый парсинг** (`requests`): честный User-Agent, пауза **не меньше 3 с** между
   запросами (меньше задать нельзя), дисковый кэш `~/.cache/cs2-analyst` (TTL 6 ч).
   На один матч уходит ~6 запросов + до 10 страниц игроков.
2. Если HLTV отвечает Cloudflare (403/429/503 или страница «Just a moment…»), инструмент
   **сразу прекращает запросы** и выходит с кодом 3. Дальше — браузер **Claude in Chrome**:
   откройте страницы в своём браузере и сохраните HTML в каталог под именами ролей,
   затем `--html-dir <каталог>`:

   | Файл | Страница |
   |---|---|
   | `match.html` | страница матча |
   | `ranking.html` | `https://www.hltv.org/ranking/teams` |
   | `team1_results.html`, `team2_results.html` | `https://www.hltv.org/results?team=<id>` |
   | `team1_maps.html`, `team2_maps.html` | `https://www.hltv.org/stats/teams/maps/<id>/<slug>` |
   | `team1_page.html`, `team2_page.html` | `https://www.hltv.org/team/<id>/<slug>` (режим `--teams`) |
   | `player_<slug>.html` | `https://www.hltv.org/stats/players/<id>/<slug>` (необязательно) |

   Либо попросите Claude in Chrome заполнить JSON-шаблон (`cs2-analyst template`).
3. Если и браузер недоступен — заполните шаблон вручную и передайте `--data`.

Инструмент **никогда** не обходит защиту: никаких прокси-ротаций, подмены IP,
решения капчи, имитации браузера. Коэффициенты букмекеров не парсятся — только `--odds`.

**Не придумывать статистику.** Любое поле, которое не удалось получить, остаётся `null`,
выводится как `[нет данных]`, снижает «полноту данных» и тянет прогноз к 50 %.

## Что считается

### Модель силы

Все факторы складываются в логит-шкале «в пользу команды 1»:

| Фактор | Как считается | Вес |
|---|---|---|
| Рейтинг HLTV | `0.7·ln(points1/points2)`; если очков нет — `0.4·ln(rank2/rank1)`; вне рейтинга = условно #45 | основной |
| Форма | матчи за 90 дней, вес `0.5^(возраст/30 дн.)`, результат минус ожидание с учётом ранга соперника, сжатие `n/(n+3)` | 1.5 |
| Игроки | средний HLTV Rating пятёрки (≥3 игрока с данными) | 3.0 на 1.00 разницы |
| H2H | последние 12 мес., `(w+2)/(n+4)` — сильное сжатие | 0.3 (малый) |
| LAN/онлайн | winrate в нужном формате со сжатием к 50 % (prior n=8) | 0.4 |
| Состав | −0.35 за каждого стендина, −0.15 при смене состава < 30 дн. | — |
| Карта | winrate карты со сжатием (prior n=5) | 0.8 |

Логит карты = `(0.75 · матчевые факторы + фактор карты) × k`, где
`k = 0.6 + 0.4·полнота_данных`. Чем меньше данных, тем ближе прогноз к 50 %.

### Карты и вето

Если вето опубликовано — используются реальные карты. Иначе вето прогнозируется жадно
(BO1: 6 банов; BO3: бан-бан-пик-пик-бан-бан-десайдер; BO5: бан-бан-4 пика-десайдер):
команда пикает свою сильнейшую и банит слабейшую карту; при наличии `pick_rate`/`ban_rate`
приоритет отдаётся привычкам команды. Прогноз вето понижает уверенность.

### Рынки

* **Матч (ML)** и **точный счёт** — точный перебор серии с разной вероятностью на каждой карте.
* **Форы по картам** (±1.5, для BO5 ±2.5) и **тотал карт** (2.5; 3.5/4.5 для BO5).
* **Победа на карте N.**
* **Раунды**: точное распределение счёта карты MR12 (до 13) с овертаймами MR3 (до 4, при
  3:3 — новый OT). Вероятность раунда калибруется так, чтобы P(победы на карте) совпала с
  моделью; CT/T-перекос берётся из `ct_round_win`/`t_round_win` (log5). Отсюда тоталы
  раундов (19.5–23.5), форы по раундам (±2.5…±5.5), вероятность овертайма.
* **Первый пистолет** — log5 по `pistol_winrate` (только если есть у обеих команд).

### Неопределённость и уверенность

* Для каждого события выводится **диапазон**: логит карты сдвигается на ±σ,
  `σ = 0.25 + 0.6·(1 − полнота) (+0.1 без вето)`.
* Уверенность: **высокая** (полнота ≥ 80 % и известно вето), **средняя** (≥ 55 %), **низкая**.

### Сравнение с коэффициентами

Для каждой переданной линии: подразумеваемая вероятность, вероятность рынка **без маржи**
(если передана пара исхода или все счета), маржа, `EV = P·кф − 1`, EV при пессимистичной
границе диапазона и размер ставки — **¼ Келли, не больше 2 % банка**.

* **перевес (value)** — EV ≥ порога и пессимистичный EV > 0;
* **слабый перевес** — EV ≥ порога, но в пределах неопределённости (ставка ≤ 1 %);
* **около справедливого / нет перевеса** — ставка 0.

Отчёт отдельно показывает **наиболее вероятные исходы** (что скорее сбудется) и
**ставки с перевесом** (что выгодно) — это разные вещи.

## Формат `--odds`

Только десятичные коэффициенты. `cs2-analyst events` выводит полный список ключей.

```json
{
  "П1": 1.55, "П2": 2.45,
  "handicap:team1:-1.5": 2.60, "handicap:team2:+1.5": 1.48,
  "total_maps:over:2.5": 2.05, "total_maps:under:2.5": 1.75,
  "score:2-0": 2.60,
  "map1:team1": 1.50, "map1 ТБ 21.5": 1.90, "map1 ТМ 21.5": 1.85,
  "map1:overtime:yes": 7.50
}
```

```csv
event,odds
Vitality,1.55
Spirit,2.45
Ф1 -1.5,2.60
```

`team1`/`team2` можно заменять названиями команд; поддерживаются синонимы П1/П2, W1/W2,
ТБ/ТМ, Ф1/Ф2. Нераспознанные ключи перечисляются в конце отчёта.

## Формат `--data`

См. `cs2-analyst template`. Проценты можно писать как `0.55`, `55` или `"55%"`.
Ключевые поля команды: `rank`, `points`, `players[{name, rating, is_standin}]`,
`recent_matches[{date, opponent, opponent_rank, won}]`,
`maps{Карта: {played, winrate, ct_round_win, t_round_win, pick_rate, ban_rate}}`,
`lan_winrate`/`lan_matches`, `online_winrate`/`online_matches`, `pistol_winrate`,
`days_since_roster_change`. Матча: `best_of`, `lan`, `event`, `date`, `map_pool`,
`veto[{name, picked_by}]`, `h2h[{date, winner}]`.

`examples/demo_match.json` — **вымышленные** команды и синтетические числа для проверки
работы, не реальная статистика.

## Ограничения

* Парсер HLTV — best-effort: при изменении вёрстки часть полей станет `[нет данных]`
  (отчёт это покажет). CT/T-раунды, pick/ban-rate и пистолеты HLTV на базовых страницах не
  отдаёт — их можно добавить через `--data`.
* Карты внутри серии считаются независимыми при заданных вероятностях (нет «моментума»).
* Не учитываются: мотивация, стадия турнира, усталость, патчи, инсайды, пинг на онлайне.
* Пул карт по умолчанию (`Ancient, Anubis, Dust2, Inferno, Mirage, Nuke, Train`) может
  устареть — передавайте `--map-pool`.

## Структура

```
cs2_analyst/
  cli.py          командная строка, шаблон, сообщения о блокировке
  fetch.py        вежливый HTTP + кэш, детектор Cloudflare, локальный каталог HTML
  hltv.py         парсеры страниц HLTV и сборщик данных
  models.py       модели данных (None = [нет данных])
  model.py        модель силы, прогноз вето, расчёт рынков, неопределённость
  probability.py  точная математика серий и раундов (MR12 + OT)
  odds.py         разбор коэффициентов, снятие маржи, EV, Келли
  report.py       отчёт Markdown / JSON
```
